# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, critique code and
ideas rather than people, and keep discussion on topic. Harassment,
discrimination, personal attacks and publishing other people's private
information are not accepted anywhere in the project's spaces.

## Enforcement

The maintainer, [@CloudArchitect101](https://github.com/CloudArchitect101),
enforces this code. To report a problem privately, use GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
feature or contact the maintainer through their GitHub profile. Reports are
kept confidential.

The maintainer may remove, edit or reject comments, commits, issues and pull
requests that break this code, and may block contributors who repeatedly or
seriously break it.
